1. How it works

Studio Helper never designs anything. It does the setup and checking around your design work:

  • Before: it creates the job folder and Illustrator/Photoshop/Figma files with every artboard already at the right size, bleed and safe-zone guides included.
  • During: you design as usual, in your own files.
  • After: it checks the print file, exports it, and watches the export folder. Every file that lands there is checked against the format it's meant to be (size, colour mode, resolution, bleed) and shown as ✓ or ✗ on the job page.

It never overwrites or deletes your .ai / .psd files.

2. Formats live in the registry

Every format (a flyer, a mall screen, a vinyl poster) is one entry in the Registry: its size, unit (mm or px), what it's exported as, and optional bleed, safe zone and scale.

  1. Registry → Open registry file. Always edit this file, not the one inside the app folder.
  2. Add or change a format, save.
  3. Validate registry. If something is wrong it tells you the line.

Job types at the bottom of the file are presets that pre-tick a group of formats, e.g. mall-print ticks every mall-print-* format.

Scale: Illustrator can't draw anything over 5.7 m. Formats over 5.5 m are drawn at 1:10 automatically; set scale: 0.1 yourself when the supplier asks for 1:10. Artboards at 1:10 are named …@1:10.

A job keeps the format sizes it was created with. Changing the registry affects new jobs only.

3. Create a job

  1. Home → New job.
  2. Name it (Cyrillic is fine; it's transliterated for file names).
  3. Pick a job type, or tick formats by hand. The preview shows every file you'll deliver.
  4. Create job. This makes a folder in Documents\Studio Jobs:
2026-09-26_autumn-sale/
  01_brief/      ← put the brief here
  02_assets/     ← logos, photos
  03_working/    ← your .ai / .psd (created for you)
  04_export/
    print/  led/  web/  social/   ← finished files go here

Every deliverable gets an exact expected file name, like 2026-09-26_autumn-sale_flyer-a5_148x210mm_v01.pdf. Files with that name in the right 04_export folder are picked up automatically.

4. Print: Illustrator

  1. On the job page: Create Illustrator print file. Illustrator opens a CMYK file in 03_working with one artboard per format (per panel for multi-panel formats), bleed set, and safe zones as locked guides on the Guides layer. Big jobs are split into _part1, _part2… files so each fits Illustrator's canvas; formats with a different bleed get their own file.
  2. Design on the Content layer. Don't rename the artboards: the name is how each one is matched to its format.
  3. Save, then Check print file. It checks without exporting: artboard sizes, bleed filled, CMYK, no RGB images, spot colours, hidden layers with content, missing artboards.
  4. Check & export print. If everything passes it writes the PDF (or TIFF for very large formats, when the registry allows both) into 04_export/print with the right name. If a check fails you get the reasons and an Export anyway button.

5. Digital: Photoshop

  1. Create Photoshop file. It makes an RGB / sRGB / 72 ppi .psd in 03_working with one artboard per screen/social format, at the exact pixel size.
  2. Design inside each artboard. Keep the artboard names.
  3. Save, then Export from Photoshop. Each artboard is exported (PNG or JPG, as the registry says) to the right 04_export folder, flattened and converted to sRGB. Your .psd isn't changed.

Video (mp4) isn't exported by Photoshop. Render it yourself with the expected name shown on the job page and drop it into 04_export/led.

6. Digital: Figma (optional)

  1. One-time: import the Studio Helper plugin (see Setup check).
  2. On the job page, Copy job.json path. In Figma, run the plugin → Create frames and give it that job.json.
  3. Design in the frames; their names already match the export file names.
  4. Export with Figma's own Export into the job's 04_export folder.

7. Checking deliverables

The table on the job page lists every expected file and updates by itself every few seconds:

  • ✗ missing nothing with that name yet
  • ✓ ok found and passes every check
  • ⚠ warning usable, but look at it (e.g. an image under the ideal ppi)
  • ✗ fail wrong size, colour mode, resolution…

Click a row to see the individual checks and what to fix. When everything shows ✓, the job is done.

8. Revisions, deleting, updates

  • Start revision when the client asks for changes: the version goes v01 → v02, so new exports get new names and the old ones stay untouched for reference.
  • Delete job moves the whole folder to Studio Jobs\_Deleted Jobs. Nothing is erased; move it back to restore it.
  • Home → Check for updates → Download & install. The app restarts itself; the previous version is kept once as a backup and older ones are cleaned up.

9. When something goes wrong

  • A button says Illustrator/Photoshop couldn't be reached: run Setup check. The job page also offers a manual way: an Open scripts folder button, then File › Scripts › Other Script… in the app.
  • "A file already exists": the app won't overwrite your work. Open the existing file, or use Start revision for a fresh one.
  • A new format doesn't appear: Registry → Validate, then create a new job (old jobs keep their formats).
  • Anything else: take a photo of the message; it says exactly what failed.
