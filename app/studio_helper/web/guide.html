How it works

Studio Helper never designs anything. It does the setup, the naming and the checking around your design work.

  • Before: it creates the job folder and the Illustrator / Photoshop / Figma files, with every artboard at the right size and bleed and safe-zone guides in place.
  • During: you design as usual, in your own files.
  • After: it checks and exports, watches the export folder and marks every file ✓ or ✕. It makes the video versions through Concat and packs the finished files for your manager.

A job page has three tabs, in the order you work: 1 · Files & export, 2 · Video, 3 · Deliver.

It never overwrites or deletes your .ai / .psd files, and your artwork never leaves your PC.

Start a job

  1. Jobs → New job, give it a name. Cyrillic is fine; file names are transliterated.
  2. Pick a preset like Mall print, or tick formats by hand. Search helps with long lists.
  3. If the print shop gave you a different bleed, change it right on the ticked format. It only affects this job.
  4. A size nobody has used before? + Custom size. Tick “save to Formats” if it’ll come back.
  5. Add the dates from the brief (print due, digital due, when it runs). The Jobs list then shows what’s due first. You can add them later with Add dates from the brief.
  6. Check the file names on the right, then Create job.

Set up the files

Step 1 on Files & export creates the working files in 03_working:

  • Illustrator: CMYK, one artboard per print format, bleed set, safe zones as locked guides. Very large formats are drawn at 1:10 and named …@1:10. Big jobs are split into _part1, _part2 files so each fits Illustrator’s canvas.
  • Photoshop: RGB / sRGB, one artboard per screen or social format at the exact pixel size.
  • Figma: Design in Figma shows how: run the Studio Helper plugin and drop in the job’s job.json.

Design

Work in your files as usual. The one rule: don’t rename the artboards. Their names are how each one is matched to its format and file name.

Print-shop notes (pockets, how far text must stay from the edge) sit next to each artboard, and on each file in the job. Click a file to see them.

Check & export

  • Check & export print checks every artboard: size, bleed filled, CMYK, image resolution, fonts, empty artboards. If everything passes, it writes the TIFF / PDF into 04_export/print with the right name. Mall print goes out as TIFF, small print as PDF.
  • If something fails, the panel says exactly what and where. Fix it, or use Export anyway.
  • Your file can stay open. Export saves your unsaved changes first, then exports. Check only never saves or closes anything.
  • Export Photoshop exports every artboard as PNG / JPG, flattened and in sRGB. Your .psd isn’t changed.
  • From Figma, export into 04_export with the file name shown on the job page. Click any file in the list to see its exact name.

The list updates by itself every few seconds:

  • missing nothing with that name yet
  • ✓ ok passes every check
  • ! check usable, worth a look
  • ✕ fail wrong size, colour mode, resolution, video length…

Videos

The Video tab makes an MP4 for every size that can be a video: Instagram and Facebook stories and posts, LED and mall screens. Each video gets its delivery name, the screen’s exact size, length limit and frame rate, no sound where screens play none, and is then checked like any export.

  1. Only pictures in this job? The tab lists your digital sizes: tick the ones that should get a video too, and Add a video for these. The picture still counts on its own.
  2. Pick how to make them. Two big cards at the top:
    • Bring your statics to life: your exported pictures move. Nothing to make anywhere else. See Statics that move.
    • Fit a Higgsfield video: one video from Higgsfield, cut to every size. See A Higgsfield video for every size.
    One click switches every size. A single size can still be made the other way: change Made from under it.
  3. Watch the preview. It plays exactly what will be made, in the browser, with nothing rendered yet. Pick any size above it, or click a size’s picture.
  4. Make all videos (or Make on one size). They’re made one after another in Concat, with progress shown. A video you exported yourself under the same name is never replaced unless you say so.
  5. Want to fine-tune one? Fine-tune in Concat opens its Concat project.

Videos are made with Concat, a free video editor you install yourself. Without it you can still set everything up and watch the previews; the tab says when it’s missing.

Statics that move

  1. Pictures. Each size starts from its exported static, shown on its card. No static yet? Export it on Files & export, or Choose another picture.
    Animating your logo or promo text? Choose a version of the picture without them (say, just the background), and add them as brand pieces, so they aren’t there twice.
  2. A 2nd picture (optional): + 2nd picture on a size, and the video changes from the first picture to the second halfway through.
  3. Motion, with the same words as Figma (see Motion words):
    • Feel: Gentle, Quick, Bouncy, Slow, or Custom. The little curve shows how a move speeds up, slows down or bounces.
    • Camera: a slow push in, pull out, or drift left, right, up or down, by a few percent. No edge of the picture ever shows.
    • Start: dissolve from black, or straight in. End: dissolve to black, hold, or Loop (the end melts back into the first frame, for screens that repeat it).
    • Length: screens with a limit get less on their own (the Paradise column: 10 s).
    • 2nd picture: how it takes over: Dissolve, Slide in, Move in or Push, from which side, and when.
  4. Copy everywhere. Set up one size the way you like it, pick it in the Preview, and press Copy everywhere next to it. Every size made from a static gets its picture, 2nd picture, motion, background and brand-piece changes.
    A picture you chose goes on every size. If it’s just that size’s exported static, it only goes where a size has no picture yet; sizes with their own export keep it. Undo on one size with Use the exported static.
  5. Every size or only one. “Change the motion for: Every size / Only one size”. A size with its own motion keeps it until you press Follow the job again.

A Higgsfield video for every size

  1. What to make in Higgsfield lists which shapes to generate (for example one 9:16 and one 3:4) and at least how big. Make reference pack copies your statics and brand pieces into 02_assets/higgsfield to feed it.
  2. Drop the Higgsfield videos on the tab. They’re copied into the job; your originals stay where they are.
  3. Draw the yellow box around what must stay visible (the juice). Every size zooms in as far as it can while the whole box stays on screen. If the subject moves, play to another moment, move the box and press Set box here.
  4. Behind the video: where a size’s shape can’t be covered, it shows Blur, Black or your Brand colour. One click switches every size; a size can have its own.
  5. Very tall strips show how much fill they need; reframe those in Higgsfield if it’s a lot. The Paradise column repeats the video 3 times around.

Brand pieces

Your logo, the line under it, a promo text like “-30%”: upload them (transparent PNG is best) and they come in one after another. Over statics they come right after the start; over a Higgsfield video they come in over the last 2 seconds, as an end card.

  • Position: one of 9 spots; pieces at the same spot stack in list order. Stories keep clear of Instagram’s own bars.
  • Size: a share of the video’s width.
  • Comes in: Dissolve, Slide in, Move in, Scale in, Pop or Instant, and from which side. When: leave it on auto, or give the second.
  • Feel: like the video, or its own (a bouncy Pop for “-30%”).
  • Goes out: stays to the end, or leaves with Dissolve, Slide out, Move out or Scale out.
  • Save to library keeps a piece for every job; it then shows at the top of the section.
  • With “Only one size” chosen in Motion, Leave it off hides a piece on that size.

Motion words

The same as Figma’s prototype animations:

  • Gentle: calm and smooth, the most neutral. The default. Quick: snappy, a little spring. Bouncy: goes past its place and settles. Slow: steady and natural, no bounce.
  • Custom spring: Mass is how heavy it is (heavier is slower and swings further), Stiffness gives more bounces, Damping makes it settle sooner. A spring’s length comes from these, like in Figma.
  • Ease in starts slowly, Ease out ends slowly, Ease in and out does both, Linear is constant. The back versions pull back a little first, or go a little past. Custom bezier takes the four numbers Figma or CSS show.
  • Dissolve fades over. Move in slides in from outside the frame. Slide in moves a little while it fades in. Push pushes the first picture out as the second comes in.

Deliver

  1. On 3 · Deliver, see which files are ready. Files that fail their checks are never packed; tick Send files with warnings too if your manager is fine with them.
  2. Make package writes one ZIP in 05_delivery, with a folder per group (mall print, mall screens, social…) and a README listing every file with its print-shop notes.
  3. After adding sizes for a new mall, pick Sizes added … to pack only those.
  4. Drag the ZIP into WeTransfer or SwissTransfer (buttons on the tab), or attach it to an email. Packed before keeps a record of what went out when.

Add sizes, reuse, revisions

  • + Add sizes: a finished campaign gets a new mall. The new sizes join the job (no new version) and are marked “added”. Then the setup step adds them: a new Illustrator file, or new artboards at the bottom of your Photoshop file. Each starts from your closest existing artwork on a “Starting point - adjust me” layer, unless you untick that.
  • Stop expecting this size (click a file): for a cancelled placement. Your files stay; restore it from the bottom of the list.
  • Reuse as new job: the same campaign with a new offer. A new job starts with copies of the old working files, Higgsfield videos and brand pieces. The old job stays exactly as it is.
  • Start revision: the version goes v01 → v02, so new exports get new names and the old ones stay for reference. Keep working in the same files; export uses your newest one.
  • More → Delete job moves the folder to Studio Jobs\_Deleted Jobs. Nothing is erased.

Formats

Every size you’ve delivered before lives in Formats: its size, bleed, what it’s delivered as, video limits, and the print shop’s notes.

  • + Add format saves a new one. So does ticking “save to Formats” on a custom size.
  • Attach the operator’s spec sheet (PDF or picture) to a format; it’s kept on your PC and linked from the format. Sizes nobody has confirmed yet show an Estimated badge.
  • Edit file opens the formats file for bigger changes; Check file tells you if something in it is wrong, and on which line.
  • Changes apply to new jobs. A job keeps the sizes it was created with; video limits and TIFF resolution follow your changes.

ChatGPT

ChatGPT on your PC can use Studio Helper: “What’s left on Black November?”, “Add the Mall X size to it”, “Make the LED videos from the statics, bouncy, with the logo popping in”.

  • It’s set up for you: every start and every update adds Studio Helper to ChatGPT’s MCP servers, with its skill. Quit and reopen ChatGPT once to see it.
  • It sees job names, sizes, file names and statuses, never your artwork. It can’t delete anything.
  • Settings → ChatGPT turns it off (and takes it out of ChatGPT), adds it again, or shows the command to paste by hand.

Settings & updates

  • Desktop shortcut: starts Studio Helper and follows every update. Delete it and it stays deleted; Put it on the desktop brings it back.
  • Video (Concat): shows whether Concat was found. Installed somewhere unusual? Paste the path to concat.exe.
  • ? → Check for updates installs the new version and restarts. One backup of the old version is kept; older ones are cleaned up, unless you saved your own files inside them.

When something goes wrong

  • Illustrator / Photoshop didn’t respond: the panel offers to run the script by hand. If it keeps happening, run Setup check.
  • “A file already exists”: the app won’t overwrite your work. Open it, or Start revision.
  • A video says “Close it in Concat first”: its project is open in the Concat window. Close it there and make it again.
  • The preview says to export the static first: that size has no picture yet. Export it, or choose one on its card.
  • A video fails its check: click it on Files & export. The reason is plain (too long, wrong size, too big a file).
  • A format looks wrong in an old job: fix it in Formats, then start a new job.
  • Anything else: take a photo of the message. It says exactly what failed.
