How it works

Studio Helper never designs anything. It does the setup and the checking around your design work.

  • Before: it creates the job folder and the Illustrator / Photoshop / Figma files, with every artboard at the right size and bleed and safe-zone guides in place.
  • During: you design as usual, in your own files.
  • After: it checks and exports the print files, then watches the export folder and marks every file ✓ or ✕.

It never overwrites or deletes your .ai / .psd files.

Start a job

  1. Jobs → New job, give it a name. Cyrillic is fine; file names are transliterated.
  2. Pick a preset like Mall print, or tick formats by hand. Search helps with long lists.
  3. If the print shop gave you a different bleed, change it right on the ticked format. It only affects this job.
  4. A size nobody has used before? + Custom size. Tick “save to Formats” if it’ll come back.
  5. Check the file names on the right, then Create job.

Set up the files

Step 1 on the job page creates the working files in 03_working:

  • Illustrator: CMYK, one artboard per print format, bleed set, safe zones as locked guides. Very large formats are drawn at 1:10 and named …@1:10. Big jobs are split into _part1, _part2 files so each fits Illustrator’s canvas.
  • Photoshop: RGB / sRGB, one artboard per screen or social format at the exact pixel size.
  • Figma: copy the job.json path and run the Studio Helper plugin → Create frames.

Design

Work in your files as usual. The one rule: don’t rename the artboards. Their names are how each one is matched to its format and file name.

Print shop notes (pockets, how far text must stay from the edge) are on each file in the job. Click a file to see them.

Check & export

  • Check & export print checks every artboard: size, bleed filled, CMYK, image resolution, fonts, empty artboards. If everything passes, it writes the TIFF / PDF into 04_export/print with the right name. Mall print goes out as TIFF, small print as PDF.
  • If something fails, the panel says exactly what and where. Fix it, or use Export anyway.
  • Export Photoshop exports every artboard as PNG / JPG, flattened and in sRGB. Your .psd isn’t changed.
  • Figma and video (mp4): export them yourself into 04_export, with the file name shown on the job page.

Delivered

The file list on the job page updates by itself every few seconds:

  • missing nothing with that name yet
  • ✓ ok passes every check
  • ! check usable, worth a look
  • ✕ fail wrong size, colour mode, resolution…

When everything is ✓, send the 04_export folder to the print shop.

Formats

Every size you’ve delivered before lives in Formats: its size, bleed, what it’s delivered as, and the print shop’s notes.

  • + Add format saves a new one. So does ticking “save to Formats” on a custom size.
  • Edit file opens the formats file for bigger changes; Check file tells you if something in it is wrong, and on which line.
  • Changes apply to new jobs. A job keeps the sizes it was created with.

Revisions, deleting, updates

  • Start revision: the version goes v01 → v02, so new exports get new names and the old ones stay for reference.
  • More → Delete job moves the folder to Studio Jobs\_Deleted Jobs. Nothing is erased.
  • ? → Check for updates installs the new version and restarts. One backup of the old version is kept; older ones are cleaned up.

When something goes wrong

  • Illustrator / Photoshop didn’t respond: the panel offers to run the script by hand. If it keeps happening, run Setup check.
  • “A file already exists”: the app won’t overwrite your work. Open it, or Start revision.
  • A format looks wrong in an old job: fix it in Formats, then start a new job.
  • Anything else: take a photo of the message. It says exactly what failed.
